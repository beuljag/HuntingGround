# HuntingGround

지정한 지점에 몹을 리젠하는 사냥터를 만드는 Paper 1.21.1 플러그인입니다.

- MythicMobs 몹과 마인크래프트 기본 몹을 스폰 지점에 설정
- 무리: 설정한 마리 수를 비슷한 위치에 소환
- 드롭템은 잡은 사람만 주울 수 있음

> **테스트 상태:** 복사본 서버에서 가짜 플레이어로 소환, 리젠, 드롭템 소유, MythicMobs 드롭 테이블, 강제 종료 후 재시작, MythicMobs 없는 환경까지 확인했습니다. 실제 클라이언트로 접속한 플레이, 플레이어가 다가왔을 때의 소환, 화살이나 늑대로 잡은 경우, 몹이 드롭템을 줍지 못하는 동작은 아직 시험하지 않았습니다.

## 설치

1. `HuntingGround-Plugin.jar`를 서버의 `plugins` 폴더에 넣습니다.
2. 서버를 재시작합니다.

MythicMobs는 없어도 작동합니다. `mythic:` 몹을 쓸 때만 필요합니다.

## 사냥터 만들기

몹이 나올 자리에 서서 명령어를 입력합니다. 서 있는 위치가 스폰 지점이 됩니다.

```
/사냥터 create 숲
/사냥터 add 숲 입구 ZOMBIE 5 6 30
/사냥터 add 숲 고블린무리 mythic:Goblin 8 4 60 GROUP
```

`add`의 순서는 `<사냥터> <지점> <몹> <마리수> [반경] [리젠초] [방식]`입니다. 위 두 줄의 뜻은 아래와 같습니다.

- **입구:** 좀비 5마리가 반경 6칸 안에 나오고, 죽은 몹은 30초 뒤에 한 마리씩 다시 나옵니다.
- **고블린무리:** 미믹몹 `Goblin` 8마리가 반경 4칸 안에 나오고, 8마리가 모두 죽으면 60초 뒤에 한꺼번에 다시 나옵니다.

| 항목 | 설명 | 생략하면 |
|---|---|---|
| 몹 | 기본 몹은 `ZOMBIE`처럼, 미믹몹은 `mythic:이름`처럼 입력 (탭 자동완성 지원) | 필수 |
| 마리수 | 함께 소환할 수 (무리 크기) | 필수 |
| 반경 | 지점 중심에서 몹이 퍼지는 거리(칸) | 5 |
| 리젠초 | 다시 나올 때까지 걸리는 시간(초) | 30 |
| 방식 | `EACH` 죽은 몹마다 따로 리젠, `GROUP` 전부 죽은 뒤 한꺼번에 리젠 | `EACH` |

미믹몹 이름은 대소문자를 구분합니다.

## 명령어

`/사냥터`와 `/huntingground`는 같은 명령어입니다. 권한은 `huntingground.admin`이고, 기본적으로 OP만 쓸 수 있습니다.

| 명령어 | 설명 |
|---|---|
| `/사냥터 create <사냥터>` | 사냥터 생성 |
| `/사냥터 delete <사냥터>` | 사냥터 삭제 (소환된 몹도 사라짐) |
| `/사냥터 list` | 사냥터 목록 |
| `/사냥터 info <사냥터>` | 지점별 몹, 현재 마리 수, 설정 확인 |
| `/사냥터 add <사냥터> <지점> <몹> <마리수> [반경] [리젠초] [방식]` | 서 있는 곳에 스폰 지점 추가 |
| `/사냥터 remove <사냥터> <지점>` | 스폰 지점 삭제 |
| `/사냥터 set <사냥터> <지점> <mob\|count\|radius\|respawn\|mode> <값>` | 스폰 지점 수정 |
| `/사냥터 set <사냥터> <지점> here` | 스폰 지점을 서 있는 곳으로 이동 |
| `/사냥터 reset [사냥터]` | 몹을 지우고 바로 다시 소환 (생략하면 전체) |
| `/사냥터 reload` | 설정 파일 다시 불러오기 |

`set`으로 값을 바꾸면 그 지점의 몹을 지우고 새 설정으로 다시 소환합니다.

## 설정

### `config.yml`

| 항목 | 설명 | 기본값 |
|---|---|---|
| `activation-range` | 지점에서 이 거리 안에 플레이어가 있어야 몹이 나옴. 0이면 청크만 로드되어 있으면 나옴 | 64 |
| `leash-range` | 몹이 지점에서 이 거리보다 멀어지면 지점으로 되돌림. 0이면 되돌리지 않음 | 40 |

### `grounds.yml`

보통은 명령어로 만들지만 파일에서 직접 고칠 수도 있습니다. 고친 뒤에는 `/사냥터 reload`를 입력합니다.

```yaml
grounds:
  숲:
    points:
      고블린무리:
        world: world
        x: 120.5
        y: 64.0
        z: -30.5
        mob: mythic:Goblin
        count: 8
        radius: 4.0
        respawn: 60
        mode: GROUP
```

## 드롭템 규칙

- 몹을 마지막으로 잡은 플레이어만 주울 수 있습니다. 화살이나 길들인 늑대로 잡아도 그 플레이어의 몫입니다.
- 기본 몹 드롭과 미믹몹 드롭 테이블에 모두 적용됩니다.
- 다른 플레이어, 몹, 호퍼는 주울 수 없습니다. 아이템이 보이기는 하지만 주워지지 않습니다.
- 용암이나 낙하처럼 플레이어가 잡지 않은 몹의 드롭템은 누구나 주울 수 있습니다.
- 주인이 줍지 않으면 바닐라 규칙대로 5분 뒤에 사라집니다.

## 알아 둘 점

- 경험치 구슬은 보호되지 않아 근처의 누구나 먹을 수 있습니다.
- 사냥터 몹은 청크에 저장되지 않습니다. 서버를 재시작하거나 청크가 내려가면 사라지고, 플레이어가 다가오면 새로 나옵니다. 그래서 몹이 쌓이지 않습니다.
- 리젠 시간은 플레이어가 멀리 있어도 흐릅니다. 시간이 다 된 몹은 플레이어가 `activation-range` 안에 들어올 때 나옵니다.
- 슬라임이 쪼개져 나온 새끼나 미믹몹 스킬로 소환된 부하처럼 플러그인이 직접 소환하지 않은 몹은 관리 대상이 아닙니다. 이 몹들의 드롭템은 누구나 주울 수 있습니다.

## 빌드

JDK 21 이상이 필요합니다. `build.bat`은 저장소가 아래 위치에 있고, Paper 1.21.1을 한 번 실행해 `libraries` 폴더가 만들어진 서버를 기준으로 컴파일합니다. MythicMobs jar도 이 서버의 `plugins` 폴더에서 가져옵니다.

```
서버/
├─ 1.20.1/                    Paper 서버 (libraries, plugins 사용)
└─ 플러그인/HuntingGround/     이 프로젝트
```

```bat
build.bat
```

결과물은 `build/HuntingGround-Plugin.jar`입니다.
